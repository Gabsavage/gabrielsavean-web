# gabrielsavean.xyz — Portfolio

Personal portfolio for Gabriel Savean — built to double as proof of the positioning it describes ("more tech than any finance/business profile, more business than any tech profile"), not a CV in HTML.

- **Live site**: gabrielsavean.xyz (soon)
- **Brief**: [`PORTFOLIO_BRIEF.md`](./PORTFOLIO_BRIEF.md) — positioning, structure, and design direction
- **Roadmap**: [`ROADMAP.md`](./ROADMAP.md) — living task list, updated as content and decisions come in

## Stack

Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion, Vercel. Case study and project content lives in MDX/JSON, decoupled from components, so adding content never requires touching code.

## Status

Early stage — architecture and content are being assembled incrementally. See `ROADMAP.md` for current progress.
